# Hackathon submission checklist

Deadline is 3 December 2026 at 00:59 WAT in Africa/Lagos. Quantum Pass requires the scaffold, QoreX, testnet deployment and a hybrid-signed transaction. The published wording leaves native-only web deployment eligibility unresolved. Obtain official clarification before claiming qualification or implementing a contract solely for submission. [Prizes](https://build.qorechain.io/prizes) · [Rules](https://build.qorechain.io/rules)

- [ ] Complete each entrant's GitHub, X and QoreX testnet registration. Confirm category and team size.
- [ ] Publish the reviewed MIT source with README, setup, API inventory, architecture, migrations, security notes, credits, AI_USAGE.md, THIRD_PARTY_NOTICES.md and .env.example. Review screenshots and evidence separately. The workspace has no initial commit or Git remote.
- [ ] Add an original featured image and demo video of up to three minutes.
- [ ] Record actual site and repository URLs, testnet addresses and verified receipts. Include a contract address only if an approved functional contract is actually deployed.
- [ ] Complete [hosted smoke tests](PRODUCTION_SMOKE_TEST.md) and [live testnet evidence](TESTNET_EVIDENCE.md). Keep private evidence, raw secrets, local databases and restricted assets out of publication.
